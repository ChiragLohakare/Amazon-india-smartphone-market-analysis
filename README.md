# Amazon-india-smartphone-market-analysis

Project Overview

This project presents an interactive Power BI dashboard analyzing 270+ smartphone models listed on Amazon India.

The objective was to perform market analysis, pricing evaluation, and performance benchmarking using structured product data.

The dashboard enables dynamic exploration of brand positioning, price segmentation, and value-for-money analysis.


Business Objectives

Analyze smartphone market distribution across brands

Segment products into Budget, Mid-Range, and Premium categories

Examine the relationship between price and performance (RAM)

Identify best value-for-money brands using Price per GB RAM

Highlight cheapest and most expensive smartphone models



Tools & Technologies

Power BI Desktop

Power Query (Data Cleaning & Transformation)

DAX (Data Analysis Expressions)

Microsoft Excel (Initial data preparation)
